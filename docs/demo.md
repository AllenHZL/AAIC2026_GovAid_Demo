# 四分鐘操作

全程使用合成資料；把頁面模型模式、案件版本和試算結果錄進影片。Gemini 負責整理條件，規則程式計算金額，MCP 讓外部 App 解釋已授權的結果。

| 時間 | 操作 | 核對 |
| --- | --- | --- |
| 0:00–0:25 | 說明租屋族查條件、備文件的困難 | 不宣稱政府已核定 |
| 0:25–0:45 | 選桃園中央租補，載入小塔／方案合成範例，建立案件 | 載入範例不是模型成果 |
| 0:45–1:05 | 儲存並試算，核對條件 | 月租 12,000，試算 2,880 |
| 1:05–1:30 | 核對目前版本，開啟指南，列印／另存 PDF | 文件、來源、版本可讀 |
| 1:30–2:15 | 開對話，送出下方更正句，查看整理資料並確認 | Gemini 只提案；確認後租金 2,500，重核對後補助 2,500 |
| 2:15–2:30 | 另建臺北租補範例 | 一般候選範例 3,600；依頁面限制說明 |
| 2:30–2:50 | 另建桃園育兒範例 | 第一名子女 5,000 |
| 2:50–3:40 | 回到原小塔租補案，透過 MCP 授權並解釋租金上限 | 同版快照、包、指南、政策 hash 一致 |
| 3:40–3:55 | 展示可讀 PDF 與官方來源 | 不代送、不保證核准 |

Gemini 更正句：

> 更正這個合成案例：每月租金是 2,500 元，其他條件不變。請先整理更正內容，讓我確認後再試算。

更正後若出現「須重新核對中央租補條件」，先打開更多申辦條件，檢查原家庭、所得年度、身分、子女資料，再將核對欄設為已核對，儲存並試算。這是條件更正後的必要確認。

MCP 提問：

> 只用 GovAid 工具讀取這個案件。若未授權，給我網址及核對字串，等我同意。請取得最新快照與同版準備包、指南和政策依據；用三句白話解釋租金 12,000 改為 2,500 後，試算為何從 2,880 變成 2,500，附官方來源。不要呼叫模型 API、改條件或代送件。

PDF：用 A4、關閉頁首／頁尾另存。核對案件 ID、版次、月租、試算金額與政策版本。MCP 讀的是結構化指南；PDF 須另交給 App 讀檔比較，不宣稱 MCP 有 PDF OCR 工具。

錄影前先完整演練；模型等待可以剪短，不能把範例資料或人工更正剪成 Gemini 自動完成，也不能省掉提案確認與案件授權。
