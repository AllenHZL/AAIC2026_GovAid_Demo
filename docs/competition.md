# 競賽交付範圍

2026-10-15 核對[官網](https://napaincu.github.io/aaic2026/)與[中文版競賽辦法](https://napaincu.github.io/aaic2026/rules/competition-rules-zh.pdf)。

- 第八節，印刷第 4 頁：初賽項目為企劃書、四分鐘內影片、場域需求與驗證資料、報名及聲明；未列原始碼。
- 第十節，印刷第 5–6 頁：入圍後須提供可運作原型、私有／公開 GitHub 或 GitLab 程式碼庫，或指定加密原始碼封裝，並附 README、文件及評測／軌跡。授權受限另依辦法提供可審查範圍與說明。
- 第十三節：程式與資料公開另須權利人同意。第十五節：初賽文件、影片及檔名需遵守匿名要求。

這份啟動包是初賽的補充重現方式，不能取代決賽的原始碼交付。開發原始碼保留於原庫的 `codex/preliminary-demo`；公開庫不複製私人 Git 歷史。

含個人帳號的公開 repo 網址是否能放進匿名送審文件，應依主辦方指定欄位與回覆處理；不要自行把開發者帳號加進匿名企劃書或影片。報名必填欄位以送件時官方表單為準。
